# SENX Web · 0.1.2

Fonte principal em `wwwroot`, usando HTML, CSS e JavaScript.
A API local consulta o PostgreSQL; não há dados demonstrativos ou persistência de negócio no navegador.
Edite esta fonte, valide com `npm test` na raiz e gere a cópia portátil com `npm run exportar`.

Documentação da versão e escopo das funcionalidades disponíveis: Obsidian / Projeto SENX - CTI.
