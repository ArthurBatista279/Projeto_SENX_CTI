# SENX v0.1 — cópia portátil para revisão

Esta pasta é gerada. A fonte principal está em Aplicacao/SenxCti.Web/wwwroot. Faça alterações nessa fonte e rode npm run exportar na raiz.

## Revisar em outra máquina

1. Copie a pasta FrontEnd inteira, incluindo assets.
2. Abra index.html no Chrome, Edge ou Firefox. Não precisa instalar .NET, PostgreSQL, Node ou qualquer pacote.
3. Use Explorar demonstração para acessar todas as telas. A página Todas as telas serve como roteiro.
4. Use Relatar problema para baixar um JSON e compartilhar com a equipe. Nada é enviado automaticamente.

Os dados são fictícios e persistem somente no navegador local. Use Restaurar demonstração para limpar os exemplos editados. Login/cadastro validam o formulário, mas não autenticam nem criam contas. Áudios selecionados não são enviados ou transcritos.

Se o navegador bloquear armazenamento em arquivos locais, a navegação continua na sessão. Opcionalmente, com Node instalado, rode npm run revisar na raiz do repositório e abra http://localhost:4173.

Versão 0.2: integrações reais dependem da estruturação do back-end, API, banco e regras de produto.
